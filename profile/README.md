# MDH-Lang – Multi-Dimensional Homomorphism Language

This GitHub organization hosts repositories related to [**Multi-Dimensional Homomorphisms (MDH)**](https://dl.acm.org/doi/10.1145/3665643).
MDH is a formalism used in compiler and performance optimization research to reason about
multi-dimensional computations and their transformations.

At present, the organization contains:
- a Python implementation of the MDH formalism, and
- the project website.

## Scope

MDH-Lang focuses on:

- formal language constructs for multi-dimensional homomorphisms,
- compiler infrastructures and intermediate representations,
- transformation and optimization pipelines,
- integration with code generation backends and runtime systems,
- evaluation on performance-critical workloads.

The repositories in this organization represent components of the MDH-Lang ecosystem, including language specification, compiler implementations, benchmarks, and supporting tools.

## Repository Overview

### pyMDH
Python implementation of the MDH formalism. This repository provides core data structures and algorithms for working with MDH objects, and serves as an executable reference for experimentation and prototyping.

Repository: `pyMDH`

### Documentation and Website
The organization also hosts documentation and web resources related to MDH, including project overviews and usage instructions.

Repository: `mdh-lang.github.io`



## Getting Started

1. If you want to use or extend the MDH formalism in Python, start with `pyMDH` and follow the README and examples in that repository.
2. For background, documentation, and project context, consult the website repository.

Questions, bug reports, and feature requests should be filed as GitHub Issues in the relevant repository.
